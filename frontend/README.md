# MATACSS Frontend

## Prerequisites

- Node.js 20+
- npm
- MATACSS backend running separately when API calls are enabled

## Setup

```powershell
npm install
Copy-Item .env.example .env.local
```

Set these values in `.env.local`:

- `NEXT_PUBLIC_API_BASE_URL`: backend URL, for example `http://127.0.0.1:8000`
- `NEXT_PUBLIC_DEMO_INTERVIEW_SESSION_ID`: an existing interview session UUID
- `NEXT_PUBLIC_DEMO_QUESTION_ID`: an existing question UUID

The demo IDs are not generated by the frontend and must refer to real,
compatible records in the backend database. Do not use placeholder UUIDs.

## Development

```powershell
npm run dev
```

Open `http://localhost:3000`.

## Production build

```powershell
npm run build
npm run start
```

The API client is defined in `lib/api.ts` and uses standard `fetch`. To test
Run Code, configure both real demo IDs, start the backend, and use the
language selector, Monaco editor, optional standard input, and Run Code button.
Submission execution is asynchronous: the frontend polls the typed submission
status endpoint and displays queued/running states before the result appears in
the output panel.
